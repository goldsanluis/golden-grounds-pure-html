# Golden Grounds Coffee Shop Website (Plain HTML)

## Overview
Golden Grounds is a simple static website fr a specialty coffee shop themed around “golden” moments. It includes:
- Home page
- Menu page
- Music & events page
- Jobs / careers page

Built with plain HTML (no CSS/JS frameworks). Open the HTML files directly in a browser.

## Brand / Tagline
**Where every sip tastes like gold.**

## Contact & Location (as shown in the pages)
- **Location:** 23 Golden Pine Road, **Caloocan City, Metro Manila**
- **Phone:** (63) 123 456 7890
- **Email:** coffee@goldengrounds.com.ph

## Pages
- **index.html** — Shop introduction + quick highlights
- **menu.html** — Menu items with prices (₱) for coffee, tea, sandwiches, bagels, muffins, and organic snacks
- **music.html** — Weekly events schedule + featured artists and poetry/spoken word performers
- **jobs.html** — Open roles (Kitchen & Drinks, Front of House, Events) + where/how to apply

## Navigation
Each page includes consistent navigation:
Home | Menu | Music | Jobs

## Assets
- `coffee-sidebar.png` — displayed as a fixed right-side image on the pages.

## How to Run
Because this is static HTML, there are no build tools or dependencies.

**Option A (recommended):** Open `index.html` in your browser.

**Option B (Windows):**
```bat
start index.html
```
